# Microsoft Power Pages

## What is Power Pages?

Microsoft Power Pages is a **low-code Software as a Service (SaaS)** platform used to build secure, external-facing business websites.

It allows organisations to create websites that connect directly to **Microsoft Dataverse**, enabling customers, suppliers, partners, and other external users to securely interact with business data.

---

## Business Value

Power Pages helps organisations:

- Build secure customer portals.
- Reduce manual emails and paperwork.
- Provide self-service experiences.
- Improve data quality.
- Reduce response times.
- Integrate with the Power Platform.

---

## Key Features

- Low-code website development
- Secure authentication
- Role-based permissions
- Dataverse integration
- Responsive website templates
- Microsoft Copilot support

---

## Integration with Power Platform

Power Pages works seamlessly with:

- Power Apps
- Power Automate
- Microsoft Dataverse
- Power BI
- Copilot Studio

---

## Microsoft Copilot

Copilot helps makers build websites using natural language.

Example:

> "Create a customer registration page that collects name, company and service interest."

Copilot can automatically:

- Create page layouts
- Build forms
- Generate Dataverse tables
- Create website content

---
