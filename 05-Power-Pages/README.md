# Microsoft Power Pages

This folder contains my notes and practical work for **Microsoft Power Pages** as part of the **PL-900: Microsoft Power Platform** certification.

Power Pages is a **low-code SaaS platform** for building secure, external-facing business websites. It enables organisations to create self-service portals where customers, partners, suppliers, and other external users can securely interact with business data stored in **Microsoft Dataverse**.

## Learning Objectives

- Understand the business value of Power Pages.
- Learn how to build secure external-facing websites.
- Explore Dataverse integration and role-based security.
- Use Microsoft Copilot to generate pages and forms.
- Create self-service portals for real-world business scenarios.
