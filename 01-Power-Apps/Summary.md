# Microsoft Power Apps

## What is Power Apps?

Microsoft Power Apps is a **low-code application development platform** that enables users to build custom business applications with minimal coding.

Applications can run on:
- Web browsers
- Windows
- Android
- iOS

---

## Business Value

Power Apps helps organisations:

- Replace paper forms and spreadsheets.
- Automate manual business processes.
- Build applications faster.
- Reduce development costs.
- Increase employee productivity.
- Reduce the workload on IT teams.

---

## Types of Power Apps

### Canvas Apps

- Fully customised user interface.
- Manual design of screens and controls.
- Best for mobile apps and simple business tasks.

### Model-driven Apps

- Built on Microsoft Dataverse.
- User interface is generated automatically.
- Best for complex business processes and data management.

---

## Microsoft Copilot

Power Apps includes Copilot, allowing users to create applications using natural language.

Copilot can:
- Create Dataverse tables
- Generate screens
- Build forms
- Produce a working starter application

---

## Key Benefits

- Low-code development
- Fast application creation
- Cross-platform support
- Microsoft 365 integration
- AI-assisted development
