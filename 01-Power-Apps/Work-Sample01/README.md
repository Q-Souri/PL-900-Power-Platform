# Work Sample – Employee Service Request App

## Overview

This work sample demonstrates a simple **Employee Service Request App** built using **Microsoft Power Apps** and **Copilot** as part of my PL-900 learning journey.

The purpose of the application is to allow employees in a small company to submit internal service requests for facilities, equipment, or office support.

---

## Scenario

An Operations Manager needs an application where employees can easily submit and track service requests.

Instead of building the application manually, Microsoft Copilot was used to generate the initial solution using a natural language prompt.

---

## Copilot Prompt

> Create an app to track employee service requests. Include requester name, department, request category, description, priority, assigned owner, due date, approval status, and request status.

---

## What Copilot Generated

Using the prompt above, Copilot automatically:

- Created a Dataverse table.
- Suggested the required columns.
- Generated sample data.
- Built the initial application layout.

The generated solution could then be refined by:

- Adding additional fields (e.g., Cost Estimate).
- Creating related tables.
- Creating relationships between tables.
- Changing data types (e.g., converting Priority into a Choice field).
- Customising the user interface.

---

## Main Features

- Employee service request submission
- Department tracking
- Request categorisation
- Priority management
- Assigned owner
- Due date tracking
- Approval status
- Request status monitoring

## Technologies Used

## Business Value

This solution demonstrates how organisations can:
