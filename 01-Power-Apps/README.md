# Power Apps

This folder contains my notes and practical work for **Microsoft Power Apps** as part of the **PL-900: Microsoft Power Platform** certification.

Microsoft Power Apps is a **low-code application development platform** that enables users to build custom business applications with minimal coding. It supports the creation of **Canvas Apps**, **Model-driven Apps**, and **mobile applications** that connect to Microsoft Dataverse and hundreds of other data sources.

## Learning Objectives

- Understand the business value of Microsoft Power Apps.
- Learn the differences between Canvas Apps and Model-driven Apps.
- Explore how Power Apps connects to Microsoft Dataverse and other data sources.
- Discover how to build low-code business applications.
- Understand how Power Apps integrates with other Microsoft Power Platform services.
