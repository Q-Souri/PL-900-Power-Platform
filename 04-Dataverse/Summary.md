# Microsoft Dataverse

## What is Dataverse?

Microsoft Dataverse is a **cloud-based data platform** that securely stores, manages, and shares business data across Microsoft Power Platform solutions.

It acts as the **central data source** for Power Apps, Power Automate, Power Pages, Power BI, and Copilot Studio.

---

## Business Value

Dataverse helps organisations:

- Store business data in one secure location.
- Eliminate duplicate and inconsistent data.
- Improve collaboration across applications.
- Strengthen security and governance.
- Enable AI-powered solutions with trusted data.
- Reduce custom development.

---

## Key Features

### Tables

Business data is stored in **tables**, made up of rows and columns, similar to a database.

Dataverse provides:

- Standard tables (Accounts, Contacts, Cases)
- Custom tables for business-specific data

---

### Security

- Role-based access control
- Field-level security
- Audit logging

---

### Business Logic

- Validation rules
- Calculated fields
- Rollup fields
- Relationships between tables

---

### Integration

Dataverse integrates with:

- Power Apps
- Power Automate
- Power Pages
- Power BI
- Microsoft 365
- Dynamics 365
- Azure
- Third-party services

---

## Common Use Cases
