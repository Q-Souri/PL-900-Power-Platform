# Microsoft Dataverse

This folder contains my learning notes and practical work for **Microsoft Dataverse** as part of the **PL-900: Microsoft Power Platform** certification.

Microsoft Dataverse is a **cloud-based data platform** that securely stores, manages, and shares business data across Microsoft Power Platform. It serves as the central data source for **Power Apps, Power Automate, Power Pages, Power BI, and Copilot Studio**, enabling all solutions to work with the same trusted data.

## Learning Objectives

- Understand the business value of Microsoft Dataverse.
- Learn how business data is organised using tables and relationships.
- Explore built-in security, business rules, and governance.
- Understand how Dataverse integrates with the Power Platform.
- Discover how Dataverse supports automation, reporting, and AI-powered solutions.
