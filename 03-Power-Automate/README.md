# Microsoft Power Automate

This folder documents information about **Microsoft Power Automate** as part of the **PL-900: Microsoft Power Platform** certification.

Power Automate is a **low-code workflow automation service** that enables organisations to automate repetitive business processes across Microsoft 365, Dataverse, Microsoft Teams, SharePoint, and hundreds of other services.

## Learning Objectives

- Understand the business value of workflow automation.
- Learn the different types of Power Automate flows.
- Explore Robotic Process Automation (RPA) and Process Mining.
- Use Microsoft Copilot to build workflows using natural language.
- Create practical automation solutions for real-world business scenarios.
