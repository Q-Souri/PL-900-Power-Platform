# Microsoft Power Automate

## What is Power Automate?

Microsoft Power Automate is a **cloud-based automation service** that enables users to create automated workflows, called **flows**, to connect applications and automate repetitive tasks.

---

## Business Value

Power Automate helps organisations:

- Automate repetitive tasks.
- Reduce manual work and errors.
- Speed up business processes.
- Improve consistency and accuracy.
- Connect multiple applications and services.
- Increase productivity.

---

## Types of Flows

### Cloud Flows

- Run in the cloud.
- Triggered automatically, on a schedule, or manually.
- Connect Microsoft 365, Dataverse, Dynamics 365 and many third-party services.

### Desktop Flows

- Use Robotic Process Automation (RPA).
- Automate tasks in desktop and legacy applications.
- Useful when applications do not have APIs.

### Process Mining

- Analyses business processes.
- Identifies bottlenecks and inefficiencies.
- Suggests automation opportunities.

---

## Microsoft Copilot

Copilot allows users to describe a workflow using natural language.

Example:

> "Notify my manager in Microsoft Teams whenever a high-priority support ticket is created."

Copilot automatically creates the flow and suggests the required connectors.

---

## Key Benefits

- Workflow automation
- Faster approvals
- AI-assisted automation
- Hundreds of connectors
- Cloud and desktop automation
- Improved process visibility
