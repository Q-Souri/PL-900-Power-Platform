# Plan Designer

This folder contains my notes and practical work for **Plan Designer** as part of the **PL-900: Microsoft Power Platform** certification.

Plan Designer is an **AI-powered planning tool** within Microsoft Power Apps that helps users transform a business problem into a complete Power Platform solution. By describing business requirements in natural language, Plan Designer generates a solution blueprint that can include apps, workflows, AI agents, websites, reports, and Microsoft Dataverse tables.

## Learning Objectives

- Understand the purpose and business value of Plan Designer.
- Learn how AI agents collaborate to design Power Platform solutions.
- Explore how Plan Designer generates apps, workflows, data models, and reports.
- Understand the role of Solution, Process, Data, and Experience Agents.
- Discover how Plan Designer accelerates low-code solution development.
